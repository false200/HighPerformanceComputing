# Ethical Considerations

Aligned with PDF §19:

- Explicit plain-language consent before campus work begins.
- Personal files are never scanned.
- Communication limited to task data, heartbeats, checkpoints, and results.
- Leave anytime; reclaim is a normal event, not a failure stigma.
- Cloud credentials stay with operators.
- Prefer anonymous node IDs in experimental logs.
- Obtain institutional lab permission where required.
- Unsigned binaries may be flagged by antivirus; distribute via trusted lab channels.

See `consent/consent_form.md` for the appendix draft.
